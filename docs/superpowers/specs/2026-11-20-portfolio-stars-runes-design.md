# Portfolio "Codex of Runes": เอกสารออกแบบ

วันที่: 2026-11-20 · เจ้าของ: Popong Faimoon (Mickie) · สถานะ: ร่าง รออนุมัติ
แบบหน้าตาอ้างอิง: Design canvas, artboard "A + B · Codex of Runes" — https://claude.ai/artifact/J2sVtve7jrdTLFZjeFT5Wr#artboard-Merged

## 1. เจตนาและเหตุผล

Mickie อยากได้ portfolio ที่ interactive และสื่อสารความเป็นตัวเองจริงๆ ไม่เหมือนเว็บใคร ตัวเองหลงใหลดาราศาสตร์ ดวงดาว เวทมนตร์ อักษรรูน และไพ่ทาโรต์ เว็บนี้ต้องรองรับผู้ชมสองแบบพร้อมกัน:

- **คนรีบ** เช่น คนคัดใบสมัครฝึกงาน ต้องเจอว่าเป็นใคร ผลงานเด่น CV และช่องทางติดต่อได้ในไม่กี่วินาที
- **คนอยากสำรวจ** ได้ค่อยๆ ค้นพบผลงานและตัวตนผ่านท้องฟ้า กลุ่มดาว และรูน

ไม่มีกำหนดส่ง Mickie ต้องการให้ทำเต็มที่และเป็นตัวเองที่สุด

## 2. เป้าหมาย / สิ่งที่ไม่ทำ / สิ่งที่ถือว่าล้มเหลว

**เป้าหมาย**
- ทางลัด (fast path) โหลดทันที และใช้ได้เต็มที่แม้ไม่มี JavaScript ฉาก 3 มิติ
- ชั้นสำรวจที่ว้าว: ท้องฟ้า 3 มิติ กลุ่มดาวผลงาน วงแหวนรูน
- ภาษาอังกฤษเป็นหลัก สลับเป็นภาษาไทยได้
- ใช้รูน Elder Futhark จริงพร้อมความหมาย

**สิ่งที่ไม่ทำ (เวอร์ชันนี้)**
- ไม่มีเพลงหรือเสียงใดๆ (Mickie ตัดสินใจตัดออก)
- ไม่มีระบบหลังบ้าน หรือ CMS
- ไม่มีบล็อก

**สิ่งที่ถือว่าล้มเหลว แม้ระบบจะทำงานได้**
- คนคัดใบสมัครต้องรอแอนิเมชันหรือฉาก 3 มิติก่อน ถึงจะเห็นผลงานหรือข้อมูลติดต่อ
- มีข้อมูลเกินจริง ตัวเลขที่แต่งขึ้น หรือบทบาทที่ไม่ตรงความจริง (ดูหัวข้อ 7)
- หน้าตาดูเหมือน template ทั่วไป หรือเหมือนเว็บ "แม่มด/แฟนตาซี" สำเร็จรูป
- ใช้ภาพที่มีลิขสิทธิ์ เช่น ภาพไพ่ทาโรต์จากสำรับที่มีอยู่แล้ว หรือเพลงประกอบภาพยนตร์

## 3. แนวทางที่พิจารณา

| แนวทาง | ข้อดี | ข้อเสีย |
|---|---|---|
| ก. ท้องฟ้า 2 มิติ (SVG/Canvas) ทั้งเว็บ | เบา ลื่นทุกอุปกรณ์ ทำเร็ว | ว้าวน้อย ให้ความรู้สึกเป็นแผนที่ ไม่ใช่อวกาศ |
| ข. 3 มิติเต็มรูปแบบ (Three.js) ทั้งเว็บ | ว้าวที่สุด | หนัก มือถือกระตุก ทางลัดต้องอยู่ในฉาก 3 มิติ ซึ่งขัดกับเป้าหมายเรื่องคนรีบ |
| **ค. ผสม (เลือกแนวทางนี้)** | ทางลัดเป็น HTML ธรรมดาที่โหลดทันที ท้องฟ้า 3 มิติโหลดตามมาทีหลัง มีท้องฟ้า 2 มิติเป็นทางสำรอง | ต้องดูแลการแสดงผลสองแบบ |

**Mickie เลือกแนวทาง ค.** เพราะได้ทั้งความเร็วสำหรับคนรีบ และความว้าวสำหรับคนสำรวจ อีกทั้งตัวเว็บเองก็เป็นผลงานวิศวกรรมชิ้นหนึ่ง

## 5. ข้อกำหนดทางเทคนิค (ข้อเสนอของ Claude, Mickie แก้ได้)

- **Stack:** Astro (static output) + Three.js เป็น island ของท้องฟ้า โหลดแบบ lazy
- **ข้อมูลผลงาน:** แหล่งเดียว ใช้ Astro content collections (ไฟล์ละผลงาน) ทั้งสองชั้นอ่านจากที่เดียวกัน
  - ฟิลด์: slug, title (en/th), summary (en/th), constellation/rune, featured + ลำดับ, status (done/in-progress), role, year, problem, tools[], links (github/demo/paper), images[], ความสว่างของดาว
- **หน้า:**
  - `/` หน้าแรก: ทางลัด + จุดเข้าท้องฟ้า
  - `/work` รายการผลงานทั้งหมด (Quick view) จัดกลุ่มตามกลุ่มดาว
  - `/work/[slug]` หน้าผลงานแต่ละชิ้น มี URL แชร์ได้ แผงในท้องฟ้ามีลิงก์มาที่หน้านี้
  - `/about` ไพ่สามใบ
  - `/cv` CV แบบ HTML + ดาวน์โหลด PDF
  - ติดต่อ: email, GitHub, LinkedIn
  - ภาษาไทยอยู่ใต้ `/th/...`
- **เงื่อนไขการแสดงท้องฟ้า 3 มิติ:**
  - ใช้ 3 มิติเมื่อมี WebGL2 และหน้าจอกว้าง ≥ 768px
  - นอกนั้นใช้ท้องฟ้า 2 มิติ (SVG/Canvas) ที่มีกลุ่มดาว วงแหวน และแผงผลงานเหมือนกัน
  - ถ้าผู้ใช้ตั้งค่า `prefers-reduced-motion` ไม่มีการบินของกล้องและไม่มีเอฟเฟกต์ถอดรหัสรูน ข้อความแสดงทันที
- **ดาวพื้นหลัง:** ใช้ตำแหน่งจริงจาก Yale Bright Star Catalogue (BSC5, public domain) ส่วนกลุ่มดาวผลงานเป็นตำแหน่งที่ออกแบบเองวางทับ
- **ฟอนต์ภาษาไทย:**
  - IBM Plex Sans Thai คู่กับ IBM Plex Mono
  - Noto Serif Thai สำหรับหัวข้อ เพราะ Cormorant ไม่มีอักษรไทย
- **การเข้าถึง (accessibility):**
  - ทุกอย่างในท้องฟ้าต้องเข้าถึงได้ผ่านรายการ HTML ด้วย
  - ดาวโฟกัสด้วยคีย์บอร์ดได้ (Tab/ลูกศร, Enter เปิดแผง, Esc ปิด)
  - ข้อความมี contrast ≥ 4.5:1
  - รูนที่เป็นของตกแต่งใส่ `aria-hidden`
- **ประสิทธิภาพ:**
  - ทางลัดไม่ขึ้นกับ JavaScript ของ Three.js
  - โหลด Three.js เมื่อ idle หรือเมื่อกด Begin
  - เป้าหมาย LCP < 2.5 วินาทีบน 4G
- **Deploy:** GitHub Actions → GitHub Pages

## 6. สิ่งที่ปล่อยให้ผู้สร้างตัดสินใจ
- จังหวะและรายละเอียดของแอนิเมชัน (การบินของกล้อง การกะพริบของดาว การถอดรหัสรูน)
- ตำแหน่งดาวในแต่ละกลุ่มดาวผลงาน (ควรอ่านเป็นรูปทรงได้ และอยู่ในวงแหวน)
- รายละเอียด shader และการเรืองแสงของรูน
- โครงสร้างโค้ดและการเขียนเทสต์
- รูปแบบของหน้า `/work`, `/cv` และการแสดงผลบนมือถือ โดยใช้ภาษาภาพเดียวกับหน้าแรก
- ลายเส้นของกรอบไพ่ทาโรต์ (ต้องเป็นงานต้นฉบับ ใช้สีทองบนน้ำเงินหมึก)
- จะใส่ฟิลเตอร์โทนทองให้ภาพ AI ทั้งสามใบดูเข้ากันหรือไม่ ให้ตัดสินจากภาพจริงที่ได้มา

## 7. ข้อจำกัดด้านเนื้อหา (ต้องตรงความจริง)
