ระบบมีสิทธิ์การเข้าถึงตามบทบาทสำหรับผู้ป่วย แพทย์ เภสัชกร พยาบาล เจ้าหน้าที่เทคนิค และผู้ดูแลระบบ ฉันออกแบบ schema PostgreSQL (21 ตาราง, 10 view, row-level security) และผู้ช่วยแชท AI แบบอ่านอย่างเดียวที่ตอบจาก view และเสนอนัดหมาย ซึ่งจะบันทึกก็ต่อเมื่อผู้ใช้ยืนยันแล้วเท่านั้น

ระบบส่งมอบเป็น Docker image โฮสต์บน Render โดยมี GitHub Actions รันเทสต์ฐานข้อมูล Edge Function, Playwright และ end-to-end ก่อนทุกการ deploy
